# 🚴‍♂️ Bike Sales Dashboard (Excel)

An interactive **Bike Sales Dashboard** built in Microsoft Excel using pivot tables, data cleaning techniques, and dynamic filtering. This project analyzes customer demographics and purchasing behavior to uncover insights about bike sales.

## 🧩 Features

* **Average Income Analysis**

  * Compare income levels between customers who purchased bikes vs those who didn’t
  * Segmented by gender

* **Age-Based Purchase Trends**

  * Visualizes bike purchases across age categories:

    * Adolescent
    * Middle Age
    * Old

* **Customer Commute Insights**

  * Shows how commute distance impacts bike purchases

* **Interactive Filters (Slicers)**

  * Marital Status
  * Region (Europe, North America, Pacific)
  * Education Level

* **KPI Card**

  * Displays total bike sales count

---

## 🛠️ Data Preparation

The dataset was cleaned and transformed before building the dashboard:

* ✅ Removed extra spaces using `TRIM`
* ✅ Standardized date formats
* ✅ Handled missing/inconsistent values
* ✅ Created a new **Age Category** column:

  * Adolescent
  * Middle Age
  * Old

---

## 📈 Data Modeling

* Built **Pivot Tables** to summarize:

  * Income vs Purchase
  * Age vs Purchase
  * Commute Distance vs Purchase

* Connected pivot tables to **Pivot Charts** for visualization

* Added **Slicers** for dynamic filtering across:

  * Marital Status
  * Region
  * Education

## 📌 Key Insights

* Middle-aged customers show the highest bike purchase rate
* Higher income groups are more likely to purchase bikes
* Shorter commute distances correlate with more purchases
* Male customers tend to have slightly higher purchase income averages
